# Fidget Universe

Eight satisfying fidget games in one site: Lava Lamp, Fidget Spinner, Slime, Mushroom Smash, Crunchy Leaves, Pixie Dust, Bug Crusher and Tomato Smash.

It is a plain static site: one `index.html` (the images are embedded inside it) plus `favicon.svg`. There is nothing to install or build.

## Run it on your computer
Open `index.html` in a browser. It needs internet for the fonts and the GSAP animation library (loaded from a CDN).

## Deploy
Import this repository in Vercel. Framework preset: **Other**. Leave the build command and output directory empty.
